# FCSEQ 0.5.1

[English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [Français](README.fr.md) · [Español](README.es.md) · [Deutsch](README.de.md) · [Português](README.pt-BR.md)

FCSEQは、ファミコンの音源で曲を作るための音楽エディタです。plitaを使った画面でノートを配置し、音色や波形を調整しながら試聴できます。GUI・CLI・Python bindingsは、同じプロジェクト形式と音声エンジンを使います。起動時は、特定のゲームに依存しない空のプロジェクトから始まります。

## インストールと表示言語

[downloads](https://github.com/bartaro/kitaqfc/tree/main/tools/fcseq/downloads)から、お使いの環境に合うZIPをダウンロードし、フォルダごと展開してください。Windowsでは`fcseq.exe`、LinuxとmacOSでは`./fcseq`を起動します。Windows・Linuxのx86_64版、MacのApple Silicon版・Intel版があります。フォントとライセンスのファイルも同じ場所に残してください。Unix系で実行権限が付いていない場合は、`chmod +x fcseq fcseq-cli`を実行します。

画面は日本語と英語に対応しています。**音源 → 日本語 / English**で切り替えられ、次回起動時にも設定が引き継がれます。NSFプレイヤーでは上部のボタンで切り替えます。初回は日本語環境なら日本語、それ以外は英語になります。環境変数`FCSEQ_LANGUAGE`に`ja`または`en`を指定することもできます。各OSで日本語を表示できるよう、Noto Sans JPを同梱しています。

WindowsではDirect3D 12対応ドライバと[Microsoft Visual C++ x64ランタイム](https://learn.microsoft.com/ja-jp/cpp/windows/latest-supported-vc-redist)が必要です。macOSではMetalを使います。Linux版はUbuntu 24.04でビルドしており、ALSA、X11またはWayland、VulkanまたはOpenGLを使います。古いディストリビューションではソースからのビルドが必要な場合があります。音声デバイスがなくてもWAVは書き出せます。実行ファイルには署名を付けておらず、macOSの公証も行っていません。

## ノートを入力する

まず**音源**メニューで使う音源を選びます。トラックの空白をダブルクリックするとノートを追加できます。ノート本体をドラッグすると位置や音程が変わり、右端をドラッグすると長さが変わります。各トラックは実際の音源の1チャンネルに対応しているため、同じトラックに重なるノートは置けません。

1トラックを大きく編集するときは、トラック名をダブルクリックするか、**E**キーを押してください。左側に鍵盤のあるキーエディタが開きます。縦方向が半音単位の音程、横方向が時間です。鍵盤をクリックすると試聴でき、ホイールで音域を上下に移動できます。鍵盤側の−/+で表示音域を拡大・縮小し、Shift+ホイールで時間方向に移動します。トラック切り替えボタンで別のトラックを開き、Eキーでもう一度全トラック表示に戻れます。ノイズ、DPCM、リズム音源では、それぞれの音や再生レートに応じた範囲を表示します。

Ctrl・Shiftを押しながらクリックするか、空白をドラッグすると複数のノートを選択できます。Ctrl+Aで現在のトラックを選択し、Ctrl+C/X/Vでコピー・切り取り・カーソル位置への貼り付け、Ctrl+Dで複製、Deleteで削除します。Ctrl+Z/Yは元に戻す・やり直す操作です。矢印キーで移動・移調、Shift+上下でオクターブ移調できます。Gでグリッドを変更し、Qで位置をグリッドに揃えます。Fは全体表示、Homeは先頭、+/-は時間方向の拡大・縮小です。

Spaceで再生・停止します。**ループ**は現在のセクションを繰り返し、**試聴**は選択したノートを再生します。ミュートとソロは書き出しにも反映されます。**曲構成**メニューではセクションの追加・名前変更・並べ替えができます。1プロジェクトに最大16セクション、各セクションに最大256小節を作れます。テンポと小節数は表示をクリックして変更してください。Ctrl+N/O/S/Shift+Sで新規作成・開く・保存・名前を付けて保存ができます。復旧用ファイルは実行ファイル横の`out/recovery_<プロセスID>.fcq`に保存されます。必要なファイルを開き、名前を付けて保存してください。

## 音源を選ぶ

基本の2A03には、矩形波2本、三角波、ノイズ、DPCMの5トラックがあります。これに拡張音源を1種類追加できます。

| 拡張音源 | 追加される音 | 合計トラック数 |
|---|---|---:|
| VRC6 | 矩形波2本、のこぎり波 | 8 |
| VRC7 | FM 6音 | 11 |
| FDS | 波形メモリ音源1音 | 6 |
| N163 | 波形メモリ音源、最大8音 | 13 |
| MMC5 | 矩形波2本、PCM | 8 |
| SUNSOFT 5B | SSG 3音、共通のノイズとエンベロープ | 8 |
| EPSM | SSG 3音、FM 6音、リズム6音 | 20 |
| VT02 | 矩形波2本、三角波、ノイズ、PCM | 10 |

音源や有効チャンネル数の変更でノートが失われる場合、変更は行いません。該当するトラックを空にするか、新規プロジェクトを作成してください。

## 音色と波形を編集する

ノートを選び、**音色・波形**を開きます。矩形波はデューティ比、ノイズは周期と長周期・短周期、VRC6ののこぎり波は加算レートで音色を変えられます。これらは固定波形なので、波形そのものを自由に描き換えることはできません。

FDSでは、全ノートで共有する64点・6ビットの波形を編集できます。N163は4ビットの波形を複数持ち、ノートごとに波形番号を選びます。グラフ上をドラッグして描くほか、サイン波・矩形波・のこぎり波・三角波のプリセットから作り始めることもできます。上下反転や左右への回転もできます。**曲線表示／直線表示**で、滑らかなカーブと折れ線を切り替えられます。表示される編集点が音源に保存する値で、曲線は点と点の間を見やすく補間したものです。サイン波の形を滑らかに確認しながら、各点の値は正確に編集できます。ポインタを近づけると点の番号と値が表示されます。

N163の波形長は4の倍数です。波形メモリの容量は全チャンネル共通で`256 − 16 × 有効チャンネル数`サンプルとなり、8音では128サンプル使えます。容量が足りないときは、別の波形を短くするかチャンネル数を減らしてください。FDSの変調テーブルとハードウェアエンベロープの編集には対応していません。

VRC7の音色0では、オペレータやエンベロープなどのパラメータを編集できます。音色1～15は合成による近似プリセットです。EPSMでは16個のFM音色を編集でき、それぞれ4つのオペレータ、アルゴリズム、フィードバック、エンベロープ、変調の設定があります。編集するオペレータを選んで調整してください。同じ音色番号を使うすべてのノートに変更が反映されます。EPSMのFMとリズムにはパン設定もあります。現在の試聴とWAV出力はモノラルですが、書き出すレジスタデータにはパン設定を保持します。

5BとEPSMのSSGでは、トーン・ノイズ・エンベロープを組み合わせられます。ノイズ周期とエンベロープ発生器は3チャンネルで共有するため、後から設定した値は同じ発生器を使う他の音にも影響します。EPSMのリズム試聴には独自に合成した打楽器音を使います。Yamahaの内蔵ROMデータは含めておらず、EPSM実機では実機内蔵のリズム音で再生されます。

## 音声ファイルを音色にする

**サンプル**を開き、WAV・FLAC・Ogg Vorbis・MP3を読み込みます。ウィンドウへのドラッグ＆ドロップでも読み込めます。開始・終了位置、ゲイン、正規化、逆再生を調整してください。元の音声は保持するため、加工はやり直せます。ステレオはモノラルに変換し、元の音声は最大60秒まで扱えます。

DPCMトラックにノートを置き、使うサンプルと再生レートを選びます。**DPCMを試聴**で変換後の音を確認し、**DMCを書き出す**で保存できます。変換時はDC成分を除去し、ローパスフィルタを通してリサンプリングします。1サンプルは最大4,081バイト、共通バンクは16,320バイトまでです。FDSではバンクが8,192バイトまでになります。大きすぎる場合は範囲を短くするか変換レートを下げてください。サンプルの変換レートと、ノートの再生レートは別の設定です。

MMC5とVT02のPCMトラックでも、同じ音声と加工設定を使えます。8ビットのPCMを4 kHzでストリーム再生し、ノートの音程で再生速度を変えます。PCMにはDPCMのバイト数制限はありません。VT02のDPCMとPCMはサンプル再生部を共有するため、1セクション内ではどちらか一方を使ってください。サンプルのループと自動ピッチ補正はありません。

## 保存と書き出し

編集可能なプロジェクトは**`.fcq`**で保存します。以前の`.fcseq`ファイルは拡張子を`.fcq`に変更してから開いてください。ノート編集用のJSON形式は`fcseq-2`を維持し、`fcseq-1`の読み込みにも対応しています。NSFを埋め込んだ再生用プロジェクトは`fcseq-3`です。

NSF・NSF2・NSFeは、ファイルメニュー、ドラッグ＆ドロップ、起動時のファイル指定で開けます。曲番号と再生時間を選んで再生してください。時間情報があればそれを使い、なければ初期値の30秒を使います。再生時間は1～600秒で指定できます。FCQに保存すると元の音楽データと再生設定を埋め込みます。任意のNSFを自動的にノートへ採譜する機能ではありません。同じ形式への再書き出しでは元のバイト列を保持します。

ノートから書き出す場合は、保存先の拡張子を`.nsf`、`.nsf2`、`.nsfe`から選びます。各セクションが1つの曲になります。NSF・NSF2を書き出すと、曲の長さとフェード0を設定したNSFeも作成します。曲はセクション末尾で停止します。エディタのループ設定とは別です。

プレイヤーはNTSC、およびNTSCで再生できる両地域対応ファイル、4 KiBバンク切り替え、上表の音源に対応します。NSF2ではタイマー割り込み、継続動作するINIT、PLAY呼び出しの抑制も扱います。PAL専用ファイルには対応していません。EPSMとNSF2タイマーはポートが重なるため、EPSMとNSF2のタイマーIRQフラグを併用するファイルはエラーにします。詳しい範囲は[音声形式の技術資料](docs/AUDIO_FORMATS.md)に記載しています。

**CコードとDPCMを書き出す**では、Cドライバ、ヘッダ、レジスタ列、サンプルバンク、配置説明を出力します。完成したゲームROMを作る機能ではありません。音源に合ったマッパーを設定し、コードとデータがCPUから読めるように配置してください。`fcseq_tick`の呼び出し周期はヘッダの`FCSEQ_TICK_RATE_HZ`に従います。通常はNTSCのフレームレート、PCMを含むプロジェクトでは4,000 Hzです。KITAQFCでは`FCSEQ_KITAQFC`を定義してください。`FCSEQ_WRITE(address, value)`で書き込み処理を差し替えることもできます。

## CLIとPython

`fcseq-cli help`でコマンド一覧を表示できます。Windowsでは末尾に`.exe`を付けます。セクション・チャンネル・ノート・音色・サンプルの番号は0から、NSFの曲番号は1から始まります。

```sh
./fcseq-cli new song.fcq epsm
./fcseq-cli validate song.fcq
./fcseq-cli render-wav song.fcq song.wav 0
./fcseq-cli export-nsf2 song.fcq song.nsf2
./fcseq-cli import-nsf music.nsf2 imported.fcq 1 60
./fcseq-cli nsf-render music.nsfe preview.wav 1 10
./fcseq-cli set-epsm-parameter song.fcq edited.fcq 0 44 4
./fcseq-cli export-kitaqfc song.fcq export
```

Python bindingsはPython 3.10以降で使えます。OSとCPUの種類に合う同梱モジュールを、プログラムと同じフォルダから読み込んでください。GUIとCLIの起動にPythonは不要です。[fcseq_native.pyi](fcseq_native.pyi)にAPI一覧があります。`set_sound`ではFCQと同じ音色設定を指定でき、SSGのエンベロープやEPSMのパンも設定できます。

```python
import fcseq_native
c = fcseq_native.Controller()
c.set_expansion('epsm')
c.set_epsm_parameter(0, 44, 4)  # 音色0のアルゴリズムを4に設定
c.add_note(0, 8, 0, 8, 69)    # EPSMの最初のFMトラック
c.set_sound(0, 8, 0, '{"instrument": 0}')
c.save_project('example.fcq')
c.export_nsf('example.nsf2')
c.render_wav('example.wav')
```

## ビルドとライセンス

Rust 1.93.1とC++14対応コンパイラを使用します。`cargo build --locked --release`でビルドし、`cargo test --locked --tests`でテストします。CLIのみの場合は`--no-default-features --bin fcseq-cli`、Python拡張は`--features python --lib`を指定します。WindowsにはMSVC Build Tools、macOSにはXcode Command Line Tools、Linuxにはリポジトリの`.github/workflows/fcseq.yml`に記載された開発用ライブラリが必要です。
