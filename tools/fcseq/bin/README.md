# FCSEQ native executables

Individual GUI (`fcseq`) and CLI (`fcseq-cli`) binaries are below each platform directory. Windows appends `.exe`. Python bindings use `fcseq_native.pyd` or `fcseq_native.so`. Prefer the [complete ZIP packages](../downloads/) so fonts, manuals, licenses and MPL source archives stay together.

See [verification](../VERIFICATION.md) and [hashes](../SHA256SUMS).
